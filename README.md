## Sobre el proyecto

Veterinary OS es una app web para veterinarias con un motor de automatización 
con IA capaz de entender conversaciones, consultar datos reales del negocio 
y ejecutar acciones (turnos, recordatorios, etc.), derivando a humanos cuando 
sea necesario.

Ver [docs/veterinary_os_project.md](docs/veterinary_os_project.md) para la visión completa y el roadmap.
